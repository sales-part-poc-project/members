`CLAUDE.md` 의 "진단 절차" 0~8단계를 처음부터 끝까지 수행하라.

인자: $ARGUMENTS

- 인자가 비어 있으면 전체 진단 (0~8단계 전부)
- `재실행` → 기존 `cc_usage_stats.json` 을 무시하고 2단계 집계부터 다시
- `요약` → 이미 만들어진 `data/` 의 최신 보고서에서 1장 · 5-5 · 5-6 만 출력 (재집계 없음)
- `말투만` → 2~4단계만 수행하고 5장(프롬프트 습관과 말투)만 출력
- `대시보드` → `python3 scripts/build_site.py --out _site && open _site/index.html` 로 통합 대시보드 로컬 미리보기 (재집계 없음)

절차·규칙·템플릿의 정본은 아래에 있다. 요약본으로 판단하지 말고 해당 문서를 읽어라.

- 절차와 위반 금지 인덱스 → `CLAUDE.md`
- 데이터 원본·집계 구간·수치 함정 → `docs/DATA_SOURCES.md`
- 보고서 0~11장 템플릿 → `docs/REPORT_TEMPLATE.md`
- 요약 JSON 스키마·금지 키 → `docs/SUMMARY_SCHEMA.md`
- `speech` 블록 필드 해설 → `docs/SPEECH_ANALYSIS.md`
- 마스킹·공유 범위·재미 코너 취급 → `docs/PRIVACY.md`

중간에 되묻지 마라. 0단계에서 이름 3줄만 받고 나머지는 끝까지 진행한다.
