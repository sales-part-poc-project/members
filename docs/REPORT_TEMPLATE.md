# 보고서 템플릿 (정본)

아래 0~11장을 **그대로** 채워 `data/{파트}_{이름}_{YYYYMMDD}.md` 로 저장한다.

**장/절 번호와 제목을 한 글자도 바꾸지 않는다.** 같은 장끼리 나란히 놓고 읽는 게 이 저장소의 존재 이유다.
내용이 없는 절은 삭제하지 말고 `데이터 없음` 으로 채운다.

모든 수치는 `cc_usage_stats.json` 에서 인용한다. 추정·반올림한 창작 수치를 쓰지 않는다.

## 4. 워크플로 패턴 — 어떻게 시키는가
- **자동화 심도**: 도구 호출 / 직접 프롬프트 = N배 (한 번 지시 → N회 도구 실행)

| 도구 | 호출수 | 비중 |
|---|---|---|

(Top 10)

- **OMC 명령어 사용 비중**: 전체 프롬프트 중 N% (omc.omc_ratio) — 슬래시 중 N% (slash_omc_ratio) · 자연어 키워드 N% (keyword_ratio)

| OMC 명령어 | 횟수 | 비중 | 이게 뜻하는 작업 |
|---|---|---|---|

(omc.commands 전부. 비중 = 횟수 / prompts_with_omc. 자연어 안의 매직 키워드 ulw·ralph 등도 포함된 수치)

- **서브에이전트/병렬 활용**: 사용한 에이전트 유형과 횟수, 서브에이전트 메시지 비중
- **모델 선택**: 모델별 비중, effort 레벨, permission mode
- **MCP 서버 / 플러그인 / 스킬**: 실제 호출된 것만
- 위 수치로부터 내 작업 방식을 3~5줄로 서술
