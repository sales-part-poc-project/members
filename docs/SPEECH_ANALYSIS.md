# 말투 분석 (`speech` 블록) 해설

한글이 포함된 자연어 프롬프트만 모아 분석한다. 슬래시 커맨드는 제외한다.
외부 형태소 분석기 없이 **종결 토큰 판정 · 조사 제거 · 정규식 마커**로 처리하므로 설치할 것이 없다.

---

## 필드

| 필드 | 읽는 법 |
|---|---|
| `sample_size` | 분석 대상 프롬프트 수. 100건 미만이면 해석에 신중할 것 |
| `politeness` | 존댓말 / 반말 / 체언종결(명사로 끝냄) 건수. **마지막 문장의 종결 토큰**으로 판정 |
| `endings_top` | 문장 끝 단어 Top 30. **그 사람의 입버릇** |
| `ending_tails_top` | 끝 2글자 Top 20. 어미 패턴이 더 뚜렷하게 보인다 |
| `first_words_top` | 프롬프트 첫 단어 Top 25. 대화를 여는 습관 |
| `vocab_top` | 조사를 떼어낸 어휘 Top 40. 관심 영역과 사고 단위 |
| `markers` · `markers_per_100` | 화법 마커 10종. `_per_100` 은 프롬프트 100건당 출현 수 → **성향 판단의 주 근거** |
| `punctuation` | 물음표·느낌표·마침표·말줄임 총 개수, 문장부호 없이 끝낸 프롬프트 수 |
| `sentences_per_prompt` | 프롬프트당 평균 문장 수, 한 문장짜리 비율 |
| `inter_prompt_gap_sec` | 같은 세션 내 프롬프트 간격(초). 중앙값·p25·p90 |
| `short_followup_ratio` | 20자 이하 짧은 후속 지시 비율. **재지시 빈도** |
| `laugh_prompts` · `emoji_prompts` | ㅋㅋ/ㅎㅎ/ㅠㅠ, 이모지를 쓴 프롬프트 수 |
| `english_mixed_ratio` | 3글자 이상 영단어가 섞인 프롬프트 비율 |
| `samples_shortest` · `samples_longest` · `samples_spread` | 실제 프롬프트 원문 표본 |

## 화법 마커 10종

각 마커가 뜻하는 바다. 100건당 수치로 비교한다.

| 마커 | 뜻 | 높으면 |
|---|---|---|
| **불만·교정** | 재지시·수정 요구 (`아니` `다시` `아직` `왜` `틀렸` `여전히`) | 완성도 기준이 높다. 또는 첫 지시가 짧아 여러 번 다듬는다 |
| **완곡·탐색** | 단정 대신 떠보기 (`혹시` `일단` `~같아` `어때` `해볼까`) | 답을 정해놓지 않고 같이 찾는 스타일 |
| **검증요구** | 확인·테스트 지시 (`확인` `검증` `테스트` `맞는지` `제대로`) | 결과를 그대로 안 믿는다. 신뢰도 관리형 |
| **강조·단정** | (`반드시` `절대` `무조건` `전부` `모두`) | 지시가 명확하다. 재량 여지를 좁힌다 |
| **칭찬·수용** | (`좋아` `굿` `완벽` `맞아` `고마워`) | 피드백을 주는 편. T/F 판단 신호 |
| **위임·자율** | (`알아서` `네가` `판단해` `자유롭게` `맡길`) | 자율성을 크게 준다 |
| **속도·긴급** | (`빨리` `급해` `지금 바로` `당장`) | 마감 압박이 잦다 |
| **범위한정** | (`이것만` `여기만` `우선` `나머지는`) | 작업을 잘게 쪼갠다 |
| **설명요구** | (`설명` `왜 그런` `이유` `근거` `알려줘`) | 결과보다 과정을 본다. 학습형 |
| **사과·완충** | (`미안` `죄송` `부탁` `참고로`) | AI 를 동료처럼 대한다 |

## 해석 요령

### 존대/반말 비율

- **반말이 압도적** → AI 를 도구로 대한다. 지시가 간결하다
- **체언종결(명사로 끝냄)이 높다** → 메모하듯 던진다. 문장을 완성하지 않는다
- **존댓말이 섞인다** → AI 를 동료처럼 대한다. `사과·완충` 마커와 함께 보면 뚜렷해진다

### 대화 리듬

- `inter_prompt_gap_sec.median` 이 **짧다(수십 초~2분)** → 반응형. 결과를 보고 바로 다음 지시
- **길다(10분 이상)** → 숙고형. 결과를 검토한 뒤 다음 지시
- `short_followup_ratio` 가 **높다** → "아니 그거 말고" 류의 재지시가 잦다.
  첫 지시를 길게 쓰는 사람은 이 값이 낮다. `prompts.len_chars.median` 과 함께 읽는다

### 어휘 지문

`vocab_top` 은 조사를 뗀 명사 중심이라 **관심 영역이 그대로 드러난다.**
`tools_all`(도구 분포)·주력 프로젝트와 겹쳐 보면 "말로 하는 것"과 "실제로 하는 것"이 일치하는지 알 수 있다.

## 반드시 할 것 — 말투 재현

지문을 근거로 **그 사람이 쓸 법한 가상 프롬프트 3개**를 지어낸다.

- 실제로 쓴 적 없는 문장이어야 한다 (표본 복사 금지)
- **종결 표현 · 첫 단어 · 어휘 · 문장 길이**를 지문에 맞춘다
- 보고서에서 사람들이 가장 재밌어하는 부분이다

예시 — 지문이 `해줘` 339 · `말야` 41 · 첫 단어 `이어서` 24 · 불만·교정 19.5/100 · 평균 3.7문장이라면:

> "이어서 그 부분도 같이 봐줘. 아까 고친 데가 아직 반영이 안 된 것 같은데 말야. 다시 확인해줘."

## 한계

- 정규식 기반이라 **반어법·농담·인용문을 구분하지 못한다**
- `sample_size` 가 작으면 마커 수치가 크게 흔들린다. 100건 미만이면 보고서에 그 사실을 명시한다
- 붙여넣은 코드·로그가 프롬프트에 섞여 있으면 어휘 지문이 오염된다
- `english_mixed_ratio` 는 한글 프롬프트만 대상으로 하므로, 영어로만 쓰는 사람은 `sample_size` 자체가 작게 잡힌다
